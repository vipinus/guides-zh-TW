# 08 · 怎麼確認真的連上了、現在從哪個地區出去

客戶端顯示「已連線」，不等於你訪問的網站看到的就是線路的地址。最省事的核對辦法就在本站頂欄：那一欄「當前網路」顯示的是**本站此刻看到的你**——從哪個國家、哪個省/州、哪家網路出來。這篇講這一欄怎麼讀、連上前後該怎麼對比、六種接入方式各自怎麼看連沒連上、地區列表的紅黃綠燈什麼意思，以及「連上了卻還顯示本地」時自己能查的幾件事。

## 頂欄「當前網路」顯示什麼

| 位置 | 內容 |
|---|---|
| 最前面 | 出口所在國家的國旗；認不出國家時換成一個 Wi‑Fi 圖示 |
| 中間 | 省/州名，按介面語言顯示（美國、加拿大、澳洲等用 CA、ON、NSW 這類通行縮寫）；香港、澳門、新加坡直接顯示地區名 |
| 後面 | 網路名：國內三大運營商、教育網等在中文介面顯示「電信」「移動」「聯通」「教育網」這類簡稱，其餘顯示英文品牌名（如 Comcast、Bell） |

- **查不到省/州時只顯示「國旗 · 網路名」**，不會拿國家名充數，國家看國旗就行。
- 電腦上把滑鼠停在這一欄，會彈出完整的機構名、省/州、國家程式碼和**出口 IP**。這個 IP 只給你自己看，找客服時它最有用。
- Windows 上的 Chrome / Edge 不帶國旗字型，國旗會顯示成兩個字母（如 JP、US），意思一樣。
- 電腦上要登入後才出現在頂欄；手機上不登入也顯示。

## 連上前後對比，一眼判斷

1. **不開線路**，開啟本站看一眼：應該是你家寬頻或手機流量的運營商，國旗是你所在的國家。
2. **連上線路**，回到瀏覽器：國旗變成你選的地區，網路名通常變成一家資料中心或雲服務商的名字，而不是家裡的運營商。
3. 兩次一樣，說明這個瀏覽器訪問本站時沒走線路，看下面「連上了還顯示本地」。

**不用反覆重新整理網頁。** 這一欄會在你切回瀏覽器視窗時自動重查，檢測到網路變動後幾秒內再補查幾次，頁面開著時也每隔十幾秒更新一次。剛連上看到的還是舊值，等十幾秒或切一下視窗；仍不變再手動重新整理。

**在國內選了「中國區入口」時**，頂欄顯示境外國家是正常的：中國區入口是分流的，國內網站從國內出去，境外網站經境外線路落地；本站在境外，顯示的自然是境外那一端。

## 各種接入方式怎麼看連沒連上

| 方式 | 客戶端裡看什麼 | 本站頂欄會不會變 |
|---|---|---|
| 思科（AnyConnect） | 客戶端顯示「已連線」 | 會，思科連上後全部流量走線路 |
| 偽裝（Hiddify） | 客戶端顯示已連線 | 全域性模式會變；「自動分流」下取決於名單 |
| 專網（OpenVPN） | 客戶端顯示已連線 | 會，預設全部流量走線路 |
| 私網（Tailscale） | 客戶端線上，**且** Exit Node 選了一個地區 | 選了出口才會變；選 None 只是裝置互訪，不走線路 |
| 代理（網頁代理） | 沒有「連線」這個狀態，看擴充套件圖示裡選的是哪個地區模式 | 只有裝了擴充套件的這個瀏覽器會變；「自動切換」規則可能讓本站直連 |
| 路由 | 管理頁裡賬號狀態正常、顯示到期時間 | 要在連著這臺路由器 Wi‑Fi 的裝置上看；分流模式下取決於名單 |

分流的意思是名單裡的網站走線路、其餘直連。開著分流時頂欄顯示本地，不一定是沒連上：**臨時切一下「全域性」再看**，變了就說明線路是通的，只是本站不在名單裡。

## 地區列表上的紅黃綠燈

思科、偽裝、代理、專網頁面的地區國旗下各有一個小燈，私網客戶端裡出口名前也有同樣的燈。它按該地區每臺伺服器的平均即時頻寬自動分檔，大約每分鐘更新一次：

| 燈 | 意思 |
|---|---|
| 綠（常亮） | 空閒 |
| 黃（閃爍） | 有人在用 |
| 紅（閃爍） | 繁忙 |
| 沒有燈 | 這會兒沒取到資料，不代表伺服器壞了 |

電腦上滑鼠停在燈上能看到該地區的平均負載。

**看到紅燈怎麼辦：**

- 紅不等於壞，只是那一刻人多，已經連上且速度夠用就不用動。
- 嫌慢就換一個綠燈的地區。思科在網頁上點另一個國旗複製新地址，偽裝匯入另一個地區的配置，私網在 Exit Node 裡換，代理在擴充套件圖示裡點另一個地區。
- 一個地區背後有多臺機器，連線時自動挑最空閒的一臺，不需要也不能自己挑機器。
- 晚 8 點到 11 點普遍擁擠，這個時段換地區比反覆重連有用。按運營商怎麼選地區見延伸閱讀。

## 連上了，但顯示的還是本地

按常見程度排：

1. **分流規則讓本站直連。** 偽裝的自動分流、代理擴充套件的「自動切換」、路由器的分流模式，都可能讓本站不走線路。臨時切全域性驗證；用代理的也可以把本站加進規則。
2. **網頁代理只管那一個瀏覽器。** 在另一個瀏覽器、手機 App 裡看，當然還是本地。
3. **私網沒選出口。** 線上≠走線路，Exit Node 是 None 時只有裝置互訪。
4. **看的裝置不對。** 路由方案要在連著那臺路由器 Wi‑Fi 的裝置上看，而不是連著光貓 Wi‑Fi 或用流量的手機。
5. **同時開了別的 VPN 或組網軟體。** 公司的 VPN、別家的加速器會搶路由，只留一個。
6. **還沒重新整理過來。** 等十幾秒、切一下視窗，或者手動重新整理一次。

## 頂欄只能告訴你 IP

頂欄看的是本站收到的那條連線的 IPv4 地址。它顯示對了，只說明這個瀏覽器訪問本站走了線路：

- **IPv6 和 DNS 看不出來。** 瀏覽器走 IPv6 訪問本站時，這一欄干脆不顯示，不會拿錯的網路冒充。影片站還提示版權限制，多半是 IPv6 或 DNS 繞過了線路，見 [03 · IPv6 和 DNS 是漏網之魚](03-ipv6-and-dns-leak.md)。
- **App 的地區判斷會快取。** 頂欄每次都是現查的，不受快取影響；但影片、音樂 App 會記住上一次的地區，徹底退出再開，見 [02 · 開了回國還是不能看](02-still-blocked-after-connecting.md)。

## 常見問題

**頂欄「當前網路」這一欄不見了？** 電腦上先登入。已登入仍不顯示，多半是這次連線走的 IPv6 或暫時查不到，等十幾秒或重新整理；它寧可不顯示，也不顯示錯的。

**同一個地區，兩次連上 IP 不一樣？** 正常。一個地區背後有多臺機器，每次連線挑當下最空閒的那臺，已連上的不會中途換走。

**顯示的省份和我想的不一樣？** 頂欄顯示的是出口 IP 所在的省/州，只精確到這一級；國旗對得上，就說明出口在你選的國家或地區。

**找客服時要報什麼？** 滑鼠停在頂欄那一欄，把彈出的內容（含出口 IP）連同接入方式、選的地區、出問題的時間一起發過去。
