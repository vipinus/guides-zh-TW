# 03 · 連上了影片站還提示版權：IPv6 和 DNS 是漏網之魚

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/overseas-video?utm_source=github&utm_content=troubleshooting-03

[02 · 開了回國還是不能看](02-still-blocked-after-connecting.md)的第 1 步過了——出口 IP 查出來是中國大陸——網站卻仍說"因版權限制無法播放"。這時九成是裝置上還有一條沒走線路的路：**IPv6** 或 **DNS**。影片站按它看到的地址判斷你在哪，只要有一條漏出去，看到的就還是海外。

## 為什麼會漏

- 現代裝置同時有 IPv4 和 IPv6 地址，瀏覽器優先用 IPv6。線路只接管 IPv4 的話，IPv6 請求直接從家裡寬帶出去。
- 瀏覽器自帶的"安全 DNS"、安卓的"私人 DNS"、另一個正在跑的組網軟體（Tailscale 之類），都會搶線上路前面接管域名解析。

"已連線"只說明隧道建立了，不代表所有流量都從隧道走。

## 五步排查

1. **看 IPv6。** 連上線路後，搜"test ipv6"開啟一個檢測頁。IPv6 那一欄顯示你所在國家的地址 → 問題就在這，去第 2 步；兩欄都是中國大陸或 IPv6 不可用 → 去第 3 步。
2. **關掉 IPv6，或換一個會攔 IPv6 的客戶端。** Windows：網絡卡屬性取消勾選"Internet 協議版本 6"。macOS：網路設定 → TCP/IP → IPv6 設為"僅本地連結"。手機：關 Wi‑Fi 用流量試一次，家庭寬頻多半有 IPv6 而運營商流量往往沒有。
3. **查 DNS。** Chrome 設定 → 隱私和安全 → 關掉"使用安全 DNS"；安卓關"私人 DNS"；退出其他 VPN、組網軟體、代理外掛。
4. **徹底退出 App 再開，網頁版清站點資料。** 平臺會快取上一次的地區判斷。
5. **換一個入口再試。** 個別出口的地址可能剛被平臺標記。

## 雷頓線路的處理

2026 年 9 月起，雷頓的三種接入方式（流量偽裝 Hiddify、思科 AnyConnect、OpenVPN）都在隧道內直接拒絕 IPv6，並強制下發 DNS 在隧道內解析——本機不用改設定。**9 月以前匯入的流量偽裝配置沒有這條規則，刪掉重新掃碼匯入一次。**

路由器方案本來就不漏：整個區域網從路由器出去，裝置的 IPv6 和 DNS 都到不了外面。

## 還會誤報的情況

| 情況 | 表現 | 解法 |
|---|---|---|
| 出口不是中國大陸 | 查 IP 是香港/臺灣/日本 | 換到中國區入口，港臺地址對騰訊、愛奇藝同樣算海外 |
| 自定義分流把影片域名設成"直連" | 網頁能開、影片不能放 | 把國內域名改成走節點；海外使用者別開"國內直連" |
| 用的是網頁代理 | 瀏覽器能看、App 不能 | 看影片要整機隧道，網頁代理只管瀏覽器 |
