# 09 · 請客服遠端幫你看電腦和路由器

有些問題在群裡來回發截圖十幾輪也說不清，客服直接看一眼螢幕兩分鐘就定位了。這篇講什麼時候值得請遠端協助、電腦上用什麼軟體、怎麼匯入本站伺服器配置、怎麼把連線資訊安全地交給客服、協助過程中你能掌控什麼、結束後怎麼收回許可權，以及裝了本站韌體的路由器需要你做什麼。

## 什麼時候值得請遠端

- 按 [01 · 連不上、慢、斷線的排查清單](01-cannot-connect-slow-drops.md) 查過一遍，帶著接入方式、地區、報錯原文或截圖、出問題的時間去問過，仍然解決不了。
- 步驟本身你說不清：設定藏得深、系統語言看不懂、報錯一閃而過截不到圖。
- 幫家裡人弄電腦，你不在他身邊，電話裡又講不明白。

以下情況**別用遠端**，改在群裡文字溝通：

- 公司統一管控的電腦。組策略通常禁止執行這類程式，而且可能違反公司規定。

## 用什麼軟體：RustDesk

網站推薦 [RustDesk](https://rustdesk.com)：開源（AGPL-3.0），程式碼可以自行審計；會話什麼時候開始、什麼時候結束都由你自己按下。支援 Windows、macOS、Linux、Android、iOS（iPhone / iPad 只能控制別人，不能被控制）。

從[聯絡頁](https://7d24hrs.com/zh-TW/contact#downloads)「下載中心」→「遠端協助」下載，或者官網 rustdesk.com；不要用搜索結果裡的第三方下載站。協助的雙方都要裝。

## 裝好之後要授權什麼

| 系統 | 要做什麼 |
|---|---|
| macOS | 「系統設定 → 隱私與安全性」裡，在「螢幕錄製」和「輔助功能」兩處都勾上 RustDesk，然後完全退出再開啟。只給一項會出現「能看不能動」或整片黑屏。提示「已損壞」見 [06](06-antivirus-false-positive.md) |
| Android | 被協助時在 RustDesk 裡點「啟動服務」、允許螢幕錄製；要讓客服能點你的螢幕，還要在系統「無障礙」裡開啟 RustDesk |
| Windows / Linux | 一般裝好直接能用 |

## 連到我們自己的伺服器

遠端協助走本站自建的 RustDesk 伺服器，國內也連得穩。**協助的雙方都要匯入一次**，兩邊用同一個伺服器才能互相找到：

1. 先登入網站，在[聯絡頁](https://7d24hrs.com/zh-TW/contact#downloads)「下載中心」→「遠端協助」→「連線本站伺服器」點「複製」。
2. 電腦上開啟 RustDesk「設定 → 網路」，先點「解鎖網路設定」，再點「ID/中繼伺服器」；手機上是「設定 → ID/中繼伺服器」。
3. 在彈出的窗口裡點右上角的剪貼簿圖示（手機上點「匯入」），配置自動填好，點「確定」。

**不要把配置貼上進輸入框**，那樣會報「failed to lookup address」。這份配置只供本站賬號使用，不要轉發。

## 把 ID 和一次性密碼交給客服

開啟 RustDesk，主介面會顯示本機的 ID 和一次性密碼。交出去之前先確認三件事：

1. **是你先提出的。** 你在[聯絡頁](https://7d24hrs.com/zh-TW/contact)上的官方群裡描述了問題，客服認為需要遠端，才進行下一步。我們的客服不會主動找你、要求你裝遠端軟體或索取連線碼；誰主動來要，都先到官方群核實。
2. **只發給官方客服渠道**：聯絡頁上列出的人工客服。群外自稱「藍盾客服」的私聊都不是我們。
3. **別發到群裡。** 群是很多人都能看到的地方，ID 加密碼等於把電腦的鑰匙貼在門上。

## 協助過程中

- 整個過程你都看得見螢幕上在做什麼，可以隨時在 RustDesk 窗口裡斷開。
- 有人要你最小化視窗、離開電腦、或者開啟網銀和支付軟體，**立刻斷開**。
- 需要輸入你的賬號密碼時，自己來輸，不要念給客服聽。

## 結束後收回許可權

1. 在 RustDesk 窗口裡點斷開，確認對方已經下線。
2. 重新整理一次性密碼，讓剛才發出去的那組作廢。
3. 退出 RustDesk。不用了可以直接解除安裝，下次需要再下載。

## 路由器：你要做什麼

裝了本站韌體的路由器，不需要在路由器或電腦上裝任何遠端軟體，也不用把路由器管理密碼發給客服。你只要：

- 保持路由器通電、網線插好，賬號已在路由器上登入。
- 在官方群裡告訴客服你的賬號、路由器型號和問題現象，其餘由客服處理。
- 處理期間別反覆拔電重啟，除非客服請你這麼做。

## 常見問題

**客服會不會主動私聊叫我裝遠端軟體？** 不會。凡是主動找上門的，一律先到官方群核實身份。

**匯入時報「failed to lookup address」？** 多半是把配置貼上進了輸入框。清空那幾欄，回到「ID/中繼伺服器」視窗點右上角的剪貼簿圖示匯入。

**macOS 上連上了但黑屏，或者看得到動不了？** 許可權沒給全，「螢幕錄製」和「輔助功能」兩處都勾上，完全退出後重開。

**協助結束了還要做什麼？** 斷開、重新整理一次性密碼、退出程式，三步做完對方就再也連不進來。
