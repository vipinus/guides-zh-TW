# 02 · 開了回國還是不能看，怎麼辦

按順序排查，每步一分鐘。

1. **確認出口 IP 真的變了。** 用瀏覽器開啟一個顯示 IP 歸屬地的網站，看是不是中國大陸。不是，說明線路沒生效，重新連線。
2. **IPv6 和 DNS 洩漏。** 出口 IP 對了但網站仍判定境外，多半是裝置的 IPv6 或本機 DNS 繞過了線路。這是最常見的一種，單獨寫了一篇：[03 · IPv6 和 DNS 是漏網之魚](03-ipv6-and-dns-leak.md)。
3. **App 快取。** 影片和音樂 App 會快取地區判定結果。徹底退出 App 再開啟，不行就清除 App 資料。
4. **App 版本。** 裝的是海外版（iQIYI、WeTV），內容庫不同，換國內版。
5. **賬號註冊地。** 少數平臺按賬號註冊時的地區限制內容，和當前 IP 無關。這種只能換賬號。
6. **系統地區和語言。** 部分 App 讀系統地區。把系統地區改成中國再試。
7. **入口地區。** 某些內容對不同省份的 IP 也有差別，換一個入口再試。

## 仍然不行

把這四樣告訴客服：目標網站或 App、報錯原文、當前出口 IP 歸屬地、用的接入方式。有這些，一次就能定位。
