人在海外，很多國內服務會因為你的 IP 不在中國大陸而拒絕：影片、音樂、政務、銀行、購票、遊戲。一篇一個場景，講清楚**為什麼被攔、怎麼解決、還有什麼坑**。

**最多人問的一篇：[在國外用路由器解鎖國內影片網站](../router/06-unlock-chinese-video-with-router.md)**——電視、盒子、全家裝置一次配置，連 Wi-Fi 就能看愛奇藝、騰訊視頻、央視頻。
