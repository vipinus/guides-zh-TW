# 09 · 驗證碼收不到與國內手機號

## 現象

政務、銀行、12306、各類 App 的簡訊驗證碼發不到你手機上，或者發了但一直不到。

## 原因

簡訊驗證碼只發給國內手機號。人在海外：國內的卡沒帶出來、或者帶出來了沒開國際漫遊、或者欠費停機。這和 IP 沒關係，換中國 IP 解決不了簡訊。

## 解法

1. **保留一張國內 SIM 卡**，出國前開通國際漫遊，選一個保號套餐。多數運營商在境外接收簡訊免費或幾乎免費。
2. **雙卡手機**：國內卡只用來收簡訊，本地卡上網，兩張卡同時在。
3. **eSIM**：部分運營商支援把國內號碼轉成 eSIM，裝在支援 eSIM 的手機上，不佔卡槽。
4. **虛擬號碼不可靠**：網上租的接碼號碼經常被平臺拉黑，註冊政務和銀行絕對不要用。

## 收到了但驗證不過

- 驗證碼有效期短，通常 5 分鐘，收到立刻填。
- 一天內多次請求驗證碼會被限流，等一小時再試。
- 人臉識別不透過多數是 App 版本或攝像頭許可權問題，裝國內版 App 並允許攝像頭。
