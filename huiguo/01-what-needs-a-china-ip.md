# 01 · 哪些服務需要中國 IP

判斷標準只有一條：服務方看到你的來源 IP 不在中國大陸，就拒絕或降級。下表按"被攔得多嚴"排序。

| 類別 | 例子 | 沒有中國 IP 會怎樣 | 除了 IP 還查什麼 |
|---|---|---|---|
| 影片 | 愛奇藝、騰訊視頻、優酷、芒果 TV、B 站部分番劇 | 提示僅限大陸地區，或只能看免費內容 | App 商店地區、賬號註冊地 |
| 音樂 | 網易雲、QQ 音樂、酷狗 | 大量歌曲灰掉不能播 | 無 |
| 政務 | 國家政務服務平臺、各省政務網、稅務、社保、公積金 | 頁面打不開或驗證碼收不到 | 手機號、人臉識別 |
| 教育 | 學信網、學位網、各校教務系統 | 打不開或極慢 | 無 |
| 出行 | 12306、航司官網 | 打不開、支付失敗 | 手機號、支付 |
| 金融 | 網銀、手機銀行、支付寶、微信支付 | 登入被風控、轉賬失敗 | SIM 卡、裝置指紋、人臉 |
| 遊戲 | 國服端遊手遊 | 能登入但延遲高、掉線 | 實名 |
| 生活 | 美團、餓了麼、滴滴、淘寶部分功能 | 定位異常、下單失敗 | 定位、手機號 |
| 直播 | 抖音、快手、鬥魚 | 部分地區不可看 | 無 |

## 一個重要的區分

**"需要中國 IP"和"需要中國手機號"是兩件事。** 影片和音樂只看 IP，換個 IP 就好；政務、銀行、購票除了 IP 還要收簡訊驗證碼、做人臉識別，IP 解決的是"能不能開啟"，後面的驗證要靠你自己的國內手機號和證件。

## 解決 IP 問題的方式

把流量先送到一臺大陸的伺服器，再由它訪問目標。做法有客戶端、網頁代理、路由器三種，選擇方法見姊妹倉庫的[各種連線方式適用的場景](../network/02-choose-your-connection-method.md)。
