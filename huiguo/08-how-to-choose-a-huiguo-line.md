# 08 · 回國線路怎麼選：國內 IP 從哪來、免費的坑在哪

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/huiguo-vpn

回國線路只做一件事：讓你在海外發出的請求，以一個**中國大陸**的 IP 到達騰訊視頻、網易雲、網銀。所以先看兩點——出口是不是真的大陸 IP，裝置上有沒有流量繞過它。速度、價格、客戶端都排在後面。

## 國內 IP 是怎麼來的

服務商必須在大陸境內有自己的伺服器。境內雲服務商開機要實名、頻寬按量計費，成本比海外機器高得多，所以正規回國服務幾乎都是付費的，國內出口數量也有限。

常見的替代做法是拿香港、臺灣、日本的機器冒充"回國"。這些地址對 B 站部分港澳臺專區有用，但騰訊視頻、愛奇藝、優酷照樣提示版權限制，網銀和 12306 也當你在海外。**判斷方法：連上以後查 IP 歸屬地，寫著"中國 · 某省"才算數。**

## 選之前核對五項

| 專案 | 怎麼看 | 不合格的表現 |
|---|---|---|
| 出口地區 | 連上後查 IP 歸屬地 | 港臺日韓地址 |
| IPv6 與 DNS | 搜"test ipv6"開啟檢測頁 | IPv6 欄顯示你所在國家 → 影片站仍會攔，見[排障 06](../troubleshooting/03-ipv6-and-dns-leak.md) |
| 客戶端 | 是不是標準協議（AnyConnect、OpenVPN、Hiddify） | 只有一個私有 App，下架就沒得用 |
| 頻寬 | 北京時間晚 8–11 點播 1080p | 白天快晚上轉圈 |
| 多裝置與路由器 | 一個賬號幾臺、能不能路由器整機接入 | 每臺裝置單獨買 |

## 免費回國線路為什麼總斷

問題不在"免費"，在成本結構。大陸出口頻寬按量付費，免費服務只能三選一：幾千人擠一臺機器，高峰期人人卡；限流量限時長，看到一半彈付費；靠別的賺錢——注入廣告、收集瀏覽記錄、把你的裝置當別人的出口。

瀏覽器上的免費"回國"外掛還有一個盲區：只代理瀏覽器的網頁請求，影片播放器、App、系統 DNS 都不走它，所以常見"網頁能開、影片不能放"。

偶爾查個資料，免費夠用；追劇、聽歌、辦網銀，穩定的付費線路省下的時間遠比訂閱費值錢。先領 24 小時試用，在晚高峰試一次再決定。

## 留學生、旅行者、家庭各怎麼配

- **留學生**：宿舍網路多半有 IPv6，用會攔 IPv6 的客戶端；網銀、學信網、12306 只在需要時連國內線路，用完斷開，減少賬號風控。
- **短期旅行**：手機裝一個思科或流量偽裝客戶端，掃碼匯入，落地即用。
- **全家常住海外**：一臺刷好韌體的路由器接進線路，電視、盒子、老人手機都不用設定，見[用路由器解鎖國內影片網站](../router/06-unlock-chinese-video-with-router.md)。

## 5 分鐘自測

1. 連上國內線路，IP 歸屬地顯示中國大陸省份。
2. IPv6 檢測頁顯示不可用或也是大陸地址。
3. 騰訊視頻隨便開一部國內獨播劇，能播。
4. 北京時間晚 8 點後再播一次 1080p，不反覆緩衝。
5. 換另一臺國內出口重複前三步。

## 常見問題

**回國 VPN 和回國加速器有區別嗎？** 沒有本質區別。"加速器"通常是遊戲或影片廠商定製的 App，只覆蓋特定應用；VPN 是整機隧道。

**用香港節點能看騰訊視頻嗎？** 不能，版權授權只覆蓋大陸。

**一個賬號幾臺裝置？** 藍盾 按檔位同時線上：個人 2 臺、家庭 4 臺、企業 8 臺；路由器算一臺，它後面的裝置不再單獨計數。同時線上超過檔位上限時，可以臨時升級賬號型別（剩餘時間按價格等值折算），用完之後再切回。

**能用 Clash 嗎？** 能。藍盾同時給 Hiddify 配置地址和 hysteria2 分享連結，Clash Meta 匯入分享連結即可；匯入後把國內域名設成走節點，別設"直連"。
