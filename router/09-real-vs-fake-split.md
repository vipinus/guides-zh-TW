# 09 · 路由器真分流和假分流有什麼區別

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/router-smart-split?utm_source=github&utm_content=router-09

同樣叫「智慧分流」，有的路由器用起來就是彆扭。分流是什麼見 [03](03-router-split-routing.md)，這篇只講怎麼從現象分辨真假，以及我們的路由器怎麼做。

## 一句話

真分流：每個網站**連同它的圖片、影片、登入一起**，按它在哪裡決定走線路還是直連，而且**家裡每臺裝置都聽同一套規則**。假分流只做到一部分，於是出現下面這些現象。

## 對照現象

| 你看到的 | 背後是怎麼回事 |
|---|---|
| 開了分流，國內網站反而變慢 | 國內網站被錯當成國外，整體繞到境外再回來，分流形同虛設 |
| 網頁能開，影片一直轉圈、圖片出不來、登入卡住 | 名單隻寫了主站，同一個網站的影片、圖片、登入走了另一條路 |
| 人在海外開著回國線路，影片 App 還提示「僅限中國大陸」 | 一部分流量沒進線路，網站看到了海外 |
| 手機能看，電視、盒子不行；某臺電腦就是不走線路 | 那臺裝置自帶網路設定，繞開了路由器 |
| 銀行、支付 App 時不時提示「異地登入」 | 同一個 App 的流量一會兒從國內出、一會兒從國外出 |
| 用著用著分流沒了（重啟、斷線重連後變成全走或全不走） | 設定沒被記住 |

這些都**不會報錯**，路由器一直顯示「已連線」，所以最難排查，很多人最後以為是線路不行。

## 真分流該做到的

- 一個網站連同網頁、圖片、影片、登入走同一條路，不拆開
- 判斷「國內還是國外」時站在正確的一邊，國內網站不繞遠
- 家裡每臺裝置同一套規則，裝置自己改的網路設定繞不過去
- 方向跟著所選地區自動變（回國、出海是兩套相反的規則）
- 名單自己更新，不用重刷
- 設定記得住：重啟、重連後不變；關掉了也不會被悄悄開啟

## 我們路由器的智慧分流

| | 怎麼做 |
|---|---|
| 開關 | 預設開啟；選國內地區=回國方向，選海外地區=出海方向，自動套用 |
| 名單 | 按「整個網站」整理：網頁連同它用到的影片、圖片、登入來源一起走 |
| 國內網站 | 出海方向下直連、不繞路，速度和沒裝路由器一樣 |
| 家裡裝置 | 統一接管，裝置自己改的網路設定照樣按規則走；沒有路由器之外的「後門」 |
| 更新 | 名單和規則隨路由器開機自動更新 |
| 記憶 | 斷線重連、重啟後保持；關了就一直是關的 |
| 區域網 | 印表機、NAS、攝像頭照常直接訪問 |

**需要你配合的一種情況**：手機或瀏覽器開了「私人 DNS」「安全 DNS」這類加密設定，裝置會自己加密去問路，路由器看不見。某臺裝置不聽話，先把這類設定關掉。

## 自己驗證

1. 人在國內（出海）：百度、淘寶速度正常；海外網站能開、影片能播。
2. 人在海外（回國）：騰訊視頻、愛奇藝隨便點一集能播，不提示「僅限中國大陸」；本地銀行、購物網站照常。
3. 每臺裝置都試，尤其電視、盒子；不聽話的先查「私人 DNS / 安全 DNS」，再確認連的是這臺路由器的 Wi‑Fi 而不是光貓的。
4. 某個網站分流下打不開：臨時切「全域性」。全域性能開、分流不能開，說明還不在名單裡，把網址發給客服加進名單，隨自動更新下發。

## 常見問題

**智慧分流要自己開啟嗎？** 不用，登入賬號、選好地區就是開的。

**回國和出海要分別設定嗎？** 不用，按所選地區自動決定方向。

**會影響印表機、NAS 嗎？** 不會，家裡網路裡的裝置照常直接訪問。
