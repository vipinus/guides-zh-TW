# 07 · 該不該上路由器，四個型號怎麼挑

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/router

路由器方案解決的是"裝置太多、有些裝不了客戶端"：線路在路由器上建一次，電視、遊戲機、音箱、老人手機全部自動走，什麼都不用裝。代價是一臺能刷韌體的路由器和十分鐘刷機。**個人、家庭、企業三檔賬號都能用路由器。**

## 該用與不該用

| 該用 | 不該用 |
|---|---|
| 家裡有電視盒子、遊戲機、Apple TV、音箱這類裝不了客戶端的裝置 | 只有一臺手機一臺電腦、以出差為主——裝客戶端更輕 |
| 家庭成員多，不想逐臺教 | 住宿舍、合租，網路不由你控制 |
| 需要 24 小時掛著的裝置（NAS、攝像頭回傳） | 主路由是運營商鎖定的光貓又不能接二級路由——用便攜路由器折中 |
| 國內辦公室或全家穩定出海，路由器上分流，裝置無感 | |

## 刷韌體還是買成品

兩條路最後跑的是同一套韌體，區別在誰來刷、出了問題誰負責。

- **自己刷**：已有 OpenWrt 支援的路由器（1000 多個型號），網站上線上編譯，3～5 分鐘後郵件收連結，照著 [02 · 自己刷韌體](02-flash-firmware-yourself.md)一步步做（有影片）。適合動手能力強、想省一臺機器錢的人。
- **買成品**：寄一臺刷好韌體的 GL.iNet，到手三步見 [01](01-plug-and-play-router.md)。適合不想折騰，或者給不懂技術的家人。

兩條路韌體都會自己更新元件，不用重新刷機；線路地址變了也不用改配置。

### 按場景速查

- 一個人出差住酒店，預算有限 → GL-MT300N-V2
- 租房、小家庭、電視和盒子要看國內或國外的影片 → GL-MT3000
- 在家用，偶爾出差也想帶著 → GL-MT3000
- 大房子、裝置多、寬頻在千兆以上，或辦公室多人共用 → GL-MT6000
- 沒有寬頻，或人經常在路上 → GL-XE3000
- 給不懂技術的父母裝一臺 → GL-MT3000 買成品，到手插電就能用

## 為什麼我們首推 GL-MT3000

- **一臺頂兩種用法**：效能夠當小家庭的主路由，體積又小到能隨身帶。四款裡只有它兩頭都佔。
- **規格不會很快過時**：Wi‑Fi 6 加 2.5G 網口，對多數家庭寬頻都有餘量。迷你款只有 2.4G 和百兆口，家裡用會成為瓶頸。
- **價格划算**：$300 附贈 24 個月個人檔服務；迷你款 $200 附贈 12 個月。把附贈的服務時長算進去，多花的 $100 換來的是高一檔的硬體再加一年服務。
- **我們最熟悉它**：自己的測試機就是這一款，新韌體先在它上面驗證，[刷機影片教程](02-flash-firmware-yourself.md)演示的也是它。遇到問題時，我們手邊有同一臺機器可以對照。

什麼時候不選它：房子大、裝置多或寬頻在千兆以上，直接上 GL-MT6000；沒有固定寬頻，選 GL-XE3000；只是出差時一個人用、想盡量省錢，GL-MT300N-V2 就夠。

## 上手後最常見的三個問題

- **Wi‑Fi 訊號弱、只有 20 dBm**：韌體按所在國家法規自動設無線功率，要等路由器聯網一次才切到你所在國家的檔位，剛刷完先插網線。
- **國內網站變慢**（人在國內）：沒開分流，全走了線路。開分流後國內 IP 直連。人在海外看國內內容同樣開分流：名單裡的國內影片域名走回國線路，其餘直連。見 [03 · 路由器分流](03-router-split-routing.md)。
- **某臺裝置不走線路**：那臺裝置自己設了私人 DNS（安卓"私人 DNS"、瀏覽器安全 DNS），關掉。

## 常見問題

**路由器算一臺裝置嗎？** 佔賬號一個名額（按檔位個人 2 臺、家庭 4 臺、企業 8 臺同時線上），它後面的裝置不再單獨計數。

**能回國看影片嗎？** 能，線路選中國區。路由器把整個區域網接進線路，裝置的 IPv6 和 DNS 都到不了外面，比手機單獨連更少出"版權限制"。見 [06](06-unlock-chinese-video-with-router.md)。

**韌體有沒有後門？** 基於 OpenWrt 編譯，只多了連線路的元件和分流規則；線路只記錄連線時長和流量總量用於計費，不記錄訪問內容。
