# 05 · 如何識別有風險的 VPN 軟體

一款 VPN 軟體的全部流量都經它的手，它想看什麼就能看什麼。市面上有兩類東西尤其要當心：一類是圈子裡叫「紅色 VPN」的——背後有監管背景、以合規名義要你實名、並把記錄上交；另一類是來路不明的免費加速器——靠你的資料、你的裝置或植入的東西賺錢。兩類的共同點是「用起來沒問題」，問題出在你看不見的地方。下面是十個能自己核實的訊號、已經裝了怎麼補救，以及一份三分鐘自測。

## 為什麼 VPN 軟體的風險比普通 App 大

VPN 是系統級的：它拿到的是裝置上所有程式的流量，包括你不知道在後臺跑的那些。普通 App 洩露的是它自己收集的資料，VPN 洩露的是你在這臺裝置上做的一切。所以選 VPN 軟體的標準要比選普通 App 嚴得多。

「用了沒事」不是安全的證據。記錄、上報、注入都發生在伺服器端或後臺，使用者端感覺不到；真出事往往在幾個月後，而且追溯不到是哪一款軟體。

## 十個訊號

- 來源不明：安裝包從群聊、網盤、二維碼傳來，沒有官網或應用商店頁面。正規客戶端要麼來自應用商店，要麼來自開發者官網，要麼來自能核對簽名的釋出頁。
- 要求裝根證書：安裝時讓你「信任證書」「安裝描述檔案」並要求信任 CA。裝了根證書，它就能解開你所有的 HTTPS 流量，包括網銀和郵箱。正常的 VPN 不需要這一步。
- 許可權過多：一個 VPN 要通訊錄、簡訊、通話記錄、精確定位、讀取相簿。VPN 只需要建立隧道的許可權，其他都用不著。
- 要求實名：註冊要身份證、人臉、國內手機號繫結。所謂合規 VPN 就是這樣把你的身份和你的流量記錄綁在一起的；正規服務只需要一個郵箱。
- 私有協議 + 閉源客戶端：只能用它自己的 App，不支援任何標準協議（AnyConnect、OpenVPN、WireGuard、Hiddify），你無法用第三方開源客戶端驗證它到底傳了什麼。
- 免費且看不出收入來源：沒有付費檔、沒有廣告、沒有企業客戶，卻常年運營。大陸出口頻寬是按量收費的，不收錢的服務總在別處收回來。
- 沒有公司、沒有客服、沒有歷史：查不到運營主體，沒有可聯絡的人，域名註冊不到一年，頻繁改名換殼。
- 後臺流量異常：不用的時候裝置也在持續上傳，電量和流量用得快。可能在把你的裝置當別人的出口，或者在同步你的資料。
- 宣傳裡強調「官方」「備案」「合法合規」並暗示別的都不合法：這是「紅色 VPN」最典型的話術，它的合規就是記錄並上報。
- 應用商店評價一邊倒、評論內容雷同、下載量與評論數不成比例：刷出來的。

## 怎麼核實

1. 看協議：官網有沒有寫明用什麼協議、能不能用第三方客戶端。能用 OpenVPN、AnyConnect、Hiddify、Tailscale 這類開源或標準客戶端連的服務，傳了什麼你可以自己抓包看。
2. 看許可權：安裝後到系統設定裡看它申請了哪些許可權，把 VPN 之外的全部關掉，關掉後還能不能用。不能用就卸。
3. 看證書：iOS 設定 → 通用 → VPN 與裝置管理，安卓設定 → 安全 → 加密與憑據 → 受信任的憑據 → 使用者，Windows 的證書管理器裡「受信任的根證書頒發機構」。有它裝的證書就刪掉並解除安裝它。
4. 查洩露：連上後開啟 DNS 洩露檢測和 IPv6 檢測頁，看解析和地址是不是都走了它的伺服器；再開啟一個 HTTPS 網站看證書頒發者是不是原本的 CA。
5. 查主體：官網有沒有公司或團隊介紹、運營多少年、客服在哪；退款規則寫沒寫；隱私政策有沒有寫清楚記錄什麼。

## 已經裝了怎麼辦

1. 解除安裝軟體，然後到上面說的位置檢查並刪除它裝的證書和描述檔案。
2. 改密碼：網銀、郵箱、常用賬號，尤其是在用它期間登入過的。
3. 開啟兩步驗證的賬號檢查登入記錄，有陌生裝置就踢掉。
4. 路由器上裝過的，恢復出廠設定後重新刷官方或可信韌體。

## 我們怎麼讓你能核實

雷騰的用戶端全部來自官方和開源社群的各個知名組織：Cisco、OpenVPN、Hiddify、Tailscale，原樣映象不修改，你隨時可以用官方或開源客戶端替換本站下載的那份。協議全是標準協議，能抓包驗證。

註冊只需要郵箱，不要手機號、不要身份證。我們只保留計費需要的資訊；不記錄訪問內容，不注入廣告，不出售資料。

不裝證書、不要通訊錄和定位。哪天我們的客戶端要你裝根證書，那一定不是我們。

## 常見問題

**免費的都不能用嗎？** 開源社群的客戶端（OpenVPN、Hiddify、Tailscale）本身是免費且可信的，風險在「免費的服務」而不是「免費的軟體」。免費服務要看它靠什麼活。

**應用商店上架的就安全嗎？** 上架只說明通過了商店的自動稽核，不代表服務端不記錄。看上面十個訊號裡的許可權、實名、協議、主體，商店本身不替你查這些。

**所謂「紅色 VPN」是什麼？** 圈子裡對有監管背景、以合規名義要求實名並留存記錄的 VPN 的叫法。它們通常宣傳自己「官方」「合法」，用起來也正常，問題是你的身份和全部流量記錄綁在了一起。

**怎麼判斷一款 VPN 有沒有記錄我的內容？** 在使用者端判斷不了，只能看它給你多少核實手段：協議是否標準、客戶端是否開源、隱私政策是否具體、運營主體是否可查。四項都沒有的，按有記錄對待。

**路由器韌體也會有這類風險嗎？** 會，來路不明的「翻牆韌體」可以劫持整個家庭網路。只刷官方 OpenWrt 或能核對來源的韌體；本站韌體基於 OpenWrt 編譯，只多了連線路的元件和分流規則。
