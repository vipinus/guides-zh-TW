# 01 · 回國訪問是怎麼回事

## 現象

人在海外，開啟愛奇藝、B 站、網易雲音樂，提示"該內容僅限中國大陸地區"；網銀和 12306 直接打不開或者驗證碼收不到。

## 原因只有一個：IP 歸屬地

你的裝置連上網時，運營商會給它一個公網 IP 地址。這個地址在全球有一張登記表，能查出它屬於哪個國家、哪家運營商。國內的影片、音樂平臺買的是**中國大陸地區**的版權，法律上不能向境外播放，所以它們看到一個境外 IP 就拒絕。

銀行和票務網站的邏輯不同，它們不是版權問題，是風控：境外 IP 登入被視為高風險，直接攔。

## 解決思路

讓伺服器看到的 IP 變成中國大陸的。做法是把你的流量先送到一臺在大陸的伺服器，再由它去訪問目標網站。目標網站看到的是那臺伺服器的 IP，自然放行。

這就是"回國線路"做的事：讓你的流量以中國大陸的 IP 出去。

## 三個常見誤區

- **改 DNS 沒用。** DNS 只負責把域名翻譯成地址，目標網站看的是你的來源 IP，不是你用的 DNS。
- **不是所有內容都能看。** 有些平臺在 IP 之外還查裝置語言、App 商店地區，遇到這種要把系統地區一起改。
- **速度取決於兩點之間的線路質量。** 海外到大陸的跨境鏈路是瓶頸，選一個離你近、且到大陸有最佳化線路的入口，比伺服器本身的配置重要。
