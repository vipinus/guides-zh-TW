# 04 · 網銀、手機銀行與支付

## 銀行的風控看什麼

銀行不只看 IP，它把幾個訊號放在一起打分：

1. **IP 歸屬地**：境外 IP 直接提高風險等級。
2. **SIM 卡**：手機銀行會讀取 SIM 資訊，境外運營商的卡是一個負分。
3. **裝置指紋**：新裝置、越獄或 root 過的裝置。
4. **行為**：新地點第一次登入就大額轉賬。

所以常見的情況是：換了中國 IP 能登入了，轉賬時仍被攔。IP 只解決了第一條。

## 能做什麼

- 換中國 IP 之後**先做小額操作**，讓風控習慣這個環境，再做大額。
- 保留國內 SIM 卡並開漫遊，驗證碼和 SIM 檢測都靠它。
- 手機銀行儘量裝國內版，商店地區問題見姊妹倉庫的 [iOS 裝不了應用怎麼辦](../client/06-ios-app-store.md)。
- 被攔了不要反覆試，多次失敗會觸發臨時凍結，打客服電話解鎖最快。

## 支付寶與微信支付

兩者對 IP 的容忍度比銀行高，海外 IP 通常能用，但繫結境外卡的賬戶有額度和場景限制。需要用國內卡付款、給國內商家轉賬時，換中國 IP 會順很多。

## 別做的事

不要在公共 Wi-Fi 上做銀行操作，不管走不走線路。線路只改變你的出口 IP，不會替你加密到銀行之外的東西，銀行 App 本身的加密才是安全的來源。
