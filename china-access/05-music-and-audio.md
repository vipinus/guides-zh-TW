# 05 · 音樂、播客與有聲書

## 現象

網易雲音樂、QQ 音樂、酷狗裡大片歌曲灰掉，提示"因版權方要求暫時無法在你所在地區播放"。喜馬拉雅、蜻蜓 FM 部分內容同理。

## 原因

和影片一樣是地區版權，只看 IP。換中國 IP 後重新整理列表，灰掉的歌會立刻恢復。

## 各平臺備註

| 平臺 | 備註 |
|---|---|
| 網易雲 | 對 IP 判斷最嚴，但換 IP 後最徹底 |
| QQ 音樂 | 部分歌曲需要會員，不是 IP 問題 |
| 酷狗 / 酷我 | 換 IP 即可 |
| 喜馬拉雅 | 部分付費專輯限地區 |

## 已下載的歌

有些 App 對本地快取也會做地區檢查，換 IP 前下載的歌可能照樣灰掉。換 IP 後重新開啟 App 即可，不用重新下載。

## 一個省事的做法

音樂類流量小，用**網頁代理**或瀏覽器方式就夠，不需要整臺裝置走線路。手機上則可以只讓音樂 App 走線路（分應用代理），其餘 App 保持本地網路，省流量也省電。
