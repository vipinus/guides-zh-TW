# 03 · 上國內政府與公共服務網站

## 現象

國家政務服務平臺、省市政務網、電子稅務局、社保公積金查詢、學信網、12306，在海外要麼打不開，要麼打開了收不到驗證碼、人臉識別不透過。

## 先分清是哪一層的問題

| 症狀 | 原因 | 解法 |
|---|---|---|
| 頁面根本打不開、超時 | 網站只對大陸 IP 開放，或跨境線路被丟包 | 換成中國 IP |
| 打開了，手機驗證碼收不到 | 簡訊要發到國內手機號 | 保留一張國內 SIM 卡，開國際漫遊接收簡訊 |
| 驗證碼收到了，人臉識別不過 | 用的是境外 App 商店版本，或攝像頭許可權 | 裝國內版 App，允許攝像頭 |
| 提示"當前網路環境異常" | 風控檢測到代理特徵 | 換一個入口地區再試，或用路由器方案（更像家庭寬頻） |

## 12306 單獨說

12306 對 IP 極敏感，境外 IP 連首頁都可能打不開。換中國 IP 後：註冊要國內手機號，購票要實名證件，支付走國內銀行卡或支付寶。三樣齊了才能買到票。搶票高峰期它還會限制單個 IP 的請求頻率，別開多個視窗刷。

## 學信網與學位認證

學信網本身對境外 IP 不算嚴，慢是主要問題。但它的驗證碼簡訊同樣只發國內號碼。留學生做學歷認證前，先確認國內手機號還能收簡訊。

## 一個建議

政務類操作往往一年就用一兩次，每次都臨時找線路很折騰。把回國線路設成一個固定入口，用完就切回去，比每次重新配置省事。
