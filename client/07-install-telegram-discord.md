# 07 · Telegram 與 Discord 的安裝

兩者都是海外華人常用的群聊工具，客服群也開在上面。安裝本身不難，卡點通常在"應用商店打不開"。

## Telegram

| 平臺 | 怎麼裝 |
|---|---|
| Windows / macOS / Linux / Android | [本站聯絡頁](https://7d24hrs.com/contact?utm_source=github&utm_content=client-07)分發官方同版本安裝包（安卓是官方完整 APK，不需要 Google Play）；也可去官網 <https://desktop.telegram.org> 或 Google Play |
| iOS | 只能 App Store，商店地區問題見[上一篇](06-ios-app-store.md) |

註冊需要一個能收簡訊的手機號，之後可以設定使用者名稱，別人不需要知道你的號碼。

## Discord

| 平臺 | 怎麼裝 |
|---|---|
| Windows / macOS / Linux | 官網 <https://discord.com/download> |
| Android | 官方只上架 Google Play。裝不了 Play 的手機可以用拆分包（.apks），需要先裝 SAI 這個開源安裝器，且只支援 arm64 機型 |
| iOS | App Store |

## 裝好後

- 進群前先看群規。多數群禁止發廣告，問問題前先搜一下群內歷史，很多問題已經有答案。
- 遇到裝不上、閃退，把系統版本和機型告訴客服，多數是機型或版本不匹配。
