# 10 · Dropbox 等軟體要填 HTTP / SOCKS 代理怎麼辦

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/app-proxy

**先說現狀：代理必須加密。** 不加密的代理（普通 HTTP、SOCKS4、SOCKS5）在國內網路上會被識別和干擾，連一會兒就變慢或斷開，賬號密碼還是明文傳輸。能長期穩定用的只有加密連線，所以本站的網頁代理只有加密這一種，**不提供 HTTP / SOCKS5 地址**。

Dropbox、Telegram 桌面版、Steam、網盤客戶端、開發工具這類獨立軟體不讀瀏覽器的設定，它們自帶的代理設定又只認不加密的 HTTP / SOCKS5——兩邊對不上，填了代理也連不上。解法是**不填代理**：用流量偽裝（Hiddify）讓整臺電腦走線路，軟體裡的代理設成「無代理」。

## 為什麼填了代理還是連不上

| 原因 | 說明 |
|---|---|
| 型別對不上 | 軟體只有 HTTP、SOCKS4、SOCKS5 選項，都不加密；本站代理必須加密，填不進去 |
| 網上找來的不加密代理 | 一時能連，隨後被幹擾，時通時不通 |
| 只管一部分 | 很多軟體只有登入和同步走代理，更新、通話、區域網同步仍直連；遊戲和通話的 UDP 流量 HTTP 代理根本不轉 |
| 每個軟體單獨維護 | 換地區、改密碼要一個個改，漏一個就那個不通 |

## 推薦做法：流量偽裝整機接管

1. 按 [09 · 偽裝（Hiddify）各平臺安裝](09-hiddify-install-all-platforms.md) 裝好 Hiddify，按 [02](02-singbox-subscription-links.md) 匯入配置。
2. 用「VPN」模式連線（預設就是）。Windows 首次連線要管理員許可權。
3. 軟體裡的代理改回「無代理」：Dropbox 在「首選項 → 網路 → 代理」選「無代理」或「自動檢測」；Telegram 桌面版在「設定 → 高階 → 連線型別」選「不使用代理」。其他軟體有代理選項的一律關掉。
4. 驗證：Dropbox 托盤圖示顯示「已是最新」、開始同步；瀏覽器開啟顯示 IP 的網頁，出口在你選的地區。

開著「自動分流」時，Dropbox 這類海外服務走線路，微信、網銀、國內網站照常直連。

## 常見軟體

| 軟體 | 怎麼設 |
|---|---|
| Dropbox | 代理「無代理」或「自動檢測」；留著「手動」和別的地址，關掉偽裝後會一直離線 |
| Telegram 桌面版 | 連線型別「不使用代理」；自帶的 MTProto / SOCKS5 疊在隧道上只會更慢 |
| OneDrive、Google Drive、iCloud 桌面版 | 跟隨系統網路，不用設 |
| Steam、Epic、戰網 | 不用設代理；下載慢換近的地區 |
| Zoom、Teams、Slack、Discord | 語音影片是 UDP，只有整機方式能帶上 |
| VS Code、JetBrains、Cursor | 跟隨系統網路；工具裡單獨設過的代理要清空 |

## 裝不了客戶端時（公司電腦）

- Dropbox、網盤用網頁版：瀏覽器裡用 [網頁代理](03-web-proxy-extension.md) 開啟 dropbox.com，能上傳下載，沒有自動同步。
- 命令列工具（git、pip、npm、curl）認加密代理：把網頁代理地址填進 `https_proxy`，見 [出海 05 · Linux 與命令列](../chuhai/05-linux-server.md)。
- 其餘只認 HTTP / SOCKS5 的桌面軟體沒有別的辦法；別為此在公司電腦上裝整機 VPN，會觸發公司的安全告警。

## 常見問題

**能不能給我一個 SOCKS5 或 HTTP 代理地址？** 不能。現狀是代理必須加密，不加密的用不了多久就時通時不通。開流量偽裝整機接管更穩，一次管所有軟體。

**開著流量偽裝，軟體裡還要填代理嗎？** 不要。填了等於繞兩次，輕則變慢、重則連不上。

**手機上的 Dropbox 呢？** 手機 App 沒有代理設定，裝 Hiddify 或用思科（AnyConnect），連上後所有 App 都走線路。

**不用流量偽裝行不行？** 行，思科、私網、專網也是整機接管，軟體同樣設「無代理」。流量偽裝的好處是自帶分流、丟包多的網路上更快。
