# 02 · Hiddify 訂閱連結、匯入連結、分享連結是什麼，要不要"訂閱轉換"

> 網站版（更長、含繁體與英文）：https://7d24hrs.com/zh-TW/guides/singbox-subscription

流量偽裝（Hiddify）的"訂閱"就是一個 HTTPS 地址，客戶端從那裡下載一份完整配置——伺服器、埠、憑據、分流規則都在裡面，不用手填。藍盾使用者登入網站後，每個地區都有自己的二維碼和配置地址。

## 三種連結

| 連結 | 長什麼樣 | 給誰用 |
|---|---|---|
| 配置地址（訂閱連結） | `https://…` | Hiddify 官方 App、GUI.for.SingBox 直接認。配置裡已含分流規則和拒絕 IPv6 的規則，不需要再套"訂閱模板" |
| 匯入連結（深鏈） | `sing-box://import-remote-profile?url=…` | 點一下喚起 App 自動新增。二維碼裡裝的就是它 |
| 分享連結 | `hysteria2://…` | 一行文本只描述一個節點，不帶規則。給 NekoBox、Shadowrocket、Stash、Clash Meta 這類不讀 Hiddify JSON 的客戶端 |

**訂閱轉換**：把一種格式轉成另一種的第三方網站。藍盾兩種格式都直接給，**不需要轉換**；把帶憑據的連結交給轉換站等於把賬號交給第三方，別這麼做。

## 手機：Hiddify 掃碼或點選匯入

1. 裝 Hiddify（安卓：網站下載頁或 Google Play；iOS：App Store）。自帶 sing-box 核心。
2. 登入網站 → 流量偽裝頁面 → 點地區國旗，出現二維碼。
3. 同一部手機：點"複製匯入連結"，切到 Hiddify 它會提示從剪貼簿新增。另一臺裝置：用 Hiddify 的"掃描二維碼"。
4. 點連線，首次允許 VPN 許可權。要加地區就再點一個國旗，每個地區是一份獨立配置。

## 桌面：貼上配置地址

1. 裝 Hiddify 桌面版（Windows / macOS / Linux）。
2. 網站上點國旗 → "複製配置地址"。桌面拿的是 https:// 地址不是深鏈，因為 Windows / Linux 上深鏈不一定能喚起 App，貼上在哪都可靠。
3. Hiddify 裡"+" → "從剪貼簿新增"，儲存，連線。

## 其他客戶端

點"複製分享連結（其他客戶端）"，在 NekoBox / Shadowrocket / Stash / Clash Meta 裡"從剪貼簿匯入"。分享連結不帶規則，分流和 IPv6 要自己設：海外看國內內容的，把國內域名設成走節點、關閉 IPv6。

## 訂閱會過期嗎

- **不會因時間過期。** 配置地址裡的令牌跟賬號繫結，賬號在有效期內就一直能用；續費、切檔都不用重導。
- **改密碼會讓舊地址立刻失效**——用來在手機丟失或連結外洩時收回訪問權，改完重新掃碼。
- **到期後**返回 401，續費後原配置不用換。
- **2026 年 9 月以前匯入的**缺拒絕 IPv6 的規則，刪掉重導。

匯入了連不上，見[排障 07](../troubleshooting/04-singbox-import-not-connecting.md)。

## 常見問題

**Hiddify 訂閱和 Clash 訂閱有什麼區別？** 格式不同（JSON vs YAML），客戶端互不認對方的訂閱，但節點本身通用。Clash Meta 用分享連結。

**一份配置能包含所有地區嗎？** 目前每個地區一份，在客戶端配置列表裡切換。這樣某個地區換地址隻影響它自己。

**二維碼能發給家人嗎？** 二維碼含你的賬號憑據，發給誰就是把賬號給誰。家人共用允許（按檔位個人 2 臺、家庭 4 臺、企業 8 臺同時線上），別發到公開的地方；洩露了改密碼即失效。
